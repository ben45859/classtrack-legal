צריכים עזרה?

מתוך האפליקציה: הגדרות ← אודות ← "שלח משוב". ההודעה תכלול את גרסת האפליקציה וגרסת iOS, כדי שנוכל לעזור מהר יותר. אנחנו משתדלים לענות תוך יומי עבודה.

שאלות נפוצות

איפה הנתונים שלי נשמרים?

רק במכשיר שלך. אין לנו שרת שמקבל אותם, ולכן גם אנחנו לא יכולים לשחזר אותם בשבילך. פרטים מלאים במדיניות הפרטיות.

איך מגבים ומשחזרים?

הגדרות ← גיבוי ושחזור ← "גבה עכשיו". הגיבויים זמינים גם באפליקציית קבצים, ומשם אפשר להעתיק אותם ל-iCloud Drive או למחשב. לשחזור: הגדרות ← גיבוי ושחזור ← "שחזר מקובץ…". לפני שחזור נשמר אוטומטית גיבוי של המצב הנוכחי.

עברתי לטלפון חדש. איך מעבירים את הנתונים?

בטלפון הישן: גבו עכשיו ושמרו את הקובץ ב-iCloud Drive (או שלחו אותו לעצמכם). בטלפון החדש: התקינו את ClassTrack, פתחו את קובץ הגיבוי או בחרו הגדרות ← גיבוי ושחזור ← "שחזר מקובץ…".

קניתי Pro ואני לא רואה אותו

הגדרות ← "שחזור רכישות". ודאו שאתם מחוברים לאותו חשבון Apple שבו נרכש המנוי.

איך מבטלים את המנוי?

הגדרות המכשיר ← השם שלכם ← מינויים ← ClassTrack, או בתוך האפליקציה: הגדרות ← "המנוי שלי". Pro נשאר פעיל עד סוף התקופה ששולמה. החזרים כספיים מטופלים על ידי Apple.

איך מכבים את נתוני השימוש האנונימיים?

הגדרות ← אודות ← "שליחת נתוני שימוש אנונימיים". הנתונים האלה לא כוללים שמות, טלפונים, סכומים או כל מידע שהזנתם.

הודעת הוואטסאפ לא נפתחת

ודאו שוואטסאפ מותקן ושמספר הטלפון של ההורה או התלמיד נשמר בפורמט תקין (למשל 050-1234567).

איך מוחקים את כל הנתונים?

מחיקת האפליקציה מהמכשיר מוחקת את כל הנתונים שבה. קבצי גיבוי ששמרתם מחוץ לאפליקציה נשארים עד שתמחקו אותם.
